<h1 align="center">Likeness Guard</h1>

<p align="center">by Basstion Forge</p>

© 2026 Basstion Forge. All rights reserved.

Likeness Guard checks whether a picture shows your face, whether it looks made or changed by AI, and helps you keep evidence and report it. All checks run on your phone.

## Download

Get the APK from [Releases](https://github.com/AustinBassWork/likeness-guard-releases/releases). Test builds are marked **Pre-release**.

## What's in this repository

This repository holds release APKs of Likeness Guard (attached to GitHub Releases) and the `update.json` manifest the app reads to check for updates.

It contains **no source code and no personal data**. The source code is kept in a separate private repository.

- `brand/icon-512.png`: the app icon
- `brand/social-preview.png`: the 1280×640 preview image for links to this page
